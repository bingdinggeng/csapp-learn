# CS:APP Bomb Lab

这是 CS:APP 3e 官方自学版 Bomb Lab。`bomb` 是带符号信息的 x86-64 ELF
可执行文件，`bomb.c` 只包含主程序；各阶段的实现需要通过反汇编推导。

## 运行

```bash
cd bomblab
make test
```

`answers.txt` 的前六行解除常规阶段，第七行解除隐藏阶段。第四行末尾的
`DrEvil` 是隐藏阶段触发词。

## 各阶段结论

### Phase 1

`phase_1` 把输入与地址 `0x402400` 处的常量字符串比较：

```text
Border relations with Canada have never been better.
```

### Phase 2

读取六个整数。第一个整数必须是 1，之后每个整数必须是前一个的两倍：

```text
1 2 4 8 16 32
```

### Phase 3

第一个整数作为跳转表索引，第二个整数必须等于对应常量。全部合法组合为：

| 索引 | 常量 |
|---:|---:|
| 0 | 207 |
| 1 | 311 |
| 2 | 707 |
| 3 | 256 |
| 4 | 389 |
| 5 | 206 |
| 6 | 682 |
| 7 | 327 |

本解选择 `0 207`。

### Phase 4

`func4(target, 0, 14)` 是二分查找，同时把搜索路径编码为返回值。阶段要求返回
值为 0，且第二个输入为 0。`target` 可以是 `0`、`1`、`3` 或 `7`，本解选择：

```text
7 0 DrEvil
```

程序在六个常规阶段结束后，会重新以 `%d %d %s` 解析第四行；第三项等于
`DrEvil` 时进入隐藏阶段。

### Phase 5

输入必须是六个字符。程序用每个字符的低 4 位作为下标，在字符串
`maduiersnfotvbyl` 中查表，结果必须为 `flyers`。目标下标依次为
`9, 15, 14, 5, 6, 7`，所以可使用：

```text
ionefg
```

### Phase 6

输入必须是 `1..6` 的一个排列。程序先把每个数替换为 `7 - x`，再以结果作为
链表节点序号，最后要求节点值按非递增顺序排列。

| 节点 | 值 |
|---:|---:|
| 1 | 332 |
| 2 | 168 |
| 3 | 924 |
| 4 | 691 |
| 5 | 477 |
| 6 | 443 |

节点的降序序号是 `3 4 5 6 1 2`。逆变换后得到：

```text
4 3 2 1 6 5
```

### Secret Phase

`fun7` 在二叉搜索树中寻找输入，并编码路径：走左边返回值乘 2，走右边返回值
乘 2 再加 1。隐藏阶段要求路径编码为 2，对应路径“左、右”和节点值：

```text
22
```

## 常用检查命令

```bash
objdump -d -M intel bomb | less
nm -n bomb
gdb ./bomb
```

在 GDB 中可先使用 `break explode_bomb`，避免调试时误入爆炸路径。
